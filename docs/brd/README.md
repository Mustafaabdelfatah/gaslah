# حزمة الـ BRD — منصة غسلة (Gaslah)

مواصفة أعمال كاملة (Business Requirements) لمنصة مغاسل SaaS متعددة المنشآت، مستخرجة من **فرع الإنتاج الحيّ** (`release/production-ready`) بتاريخ 2026-08-26.

## الهدف
إعادة بناء **نفس البيزنس بالظبط** بكود نضيف وبنية جديدة — بدون الرجوع للكود القديم. كل ملف يوثّق الكيانات (بكل حقولها)، التدفقات خطوة بخطوة، قواعد البيزنس المرقّمة، آلات الحالات، الأدوار والصلاحيات لكل عملية، حركة الفلوس، والفجوات المعروفة.

## كيف تستخدمها في شات جديد
1. **ابدأ بـ [`00-overview-architecture.md`](00-overview-architecture.md)** — فيه المفاهيم والأنماط المشتركة (نزاهة الفلوس، الأمان، التزامن) اللي كل الملفات تفترض معرفتها.
2. حمّل ملف الموديول اللي بتشتغل عليه. كل ملف مستقل وقابل للتنفيذ بمفرده.
3. الملفات تركّز على **البيزنس** — طبقة الـ API (أشكال request/response) تصمّمها أنت بناءً على المنطق الموصوف.
